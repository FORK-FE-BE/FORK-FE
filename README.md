# 🍽️ FORK
**AR을 이용한 음식 배달 서비스**

## 💡 작품 개요
**창업지원프로그램에서 진행한 프로젝트로 AR를 이용한 배달 어플리케이션 입니다.**
구매자는 AR을 이용해 사진과 다른 실제 음식의 문제점을 해결하고
크기와 세부 정보까지 알 수 있습니다.

## 🛠️ 적용 기술 및 구조
**개발 환경**: Windows, Mac OS, Xcode<br>
**개발 도구**: Visual Studio Code, IntelliJ, MySQL workbench, iOS Simulator, Postman<br>
**개발 언어**: JavaScript, TypeScript, SQL<br>
**주요 기술**: React Native, Expo, React Navigation
